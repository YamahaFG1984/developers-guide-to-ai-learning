# 第 12 章 · 从工作流到自主智能体

> Part V 开篇。本章无代码，是 agent 的概念框架。

## 📖 场景引入：AI 走进工作流

创业团队成功微调了邮件分类模型，混乱的收件箱变成了有序的系统。邮件被整齐地标为 Sales Lead、Support Queries、Partnership Ideas。**雪崩被驯服了。**

**但分类虽然关键，只是第一步。** 分好类的邮件仍堆在数字文件夹里，每个类别都需要不同的、耗时的人工动作：

- **Sales Lead 文件夹**：需要调研公司、找联系方式、起草个性化外联
- **Support Queries 文件夹**：需要知识库搜索和定制回复
- **Partnership Ideas 文件夹**：可能涉及竞品分析或安排通话

> **瓶颈只是往下游移动了。人类团队依然在溺水——不是溺在未分类的邮件里，而是溺在分好类的邮件产生的复杂手工跟进任务里。**

**这些也不是简单的文本生成任务。** 每个都需要：

- 在不同软件间导航
- 访问外部网站
- 执行搜索
- **基于收集到的信息做小的决策**
- 通过各种数字工具（CRM、日历、搜索引擎、邮件撰写器）**按特定顺序编排多个步骤**

**它是动态的，需要与 AI 内部知识之外的数字世界交互，远远超出了生成一段文本或应用一个标签。**

> **问题从"AI 能理解并标记这封邮件吗？"戏剧性地转变为——**
>
> **"AI 能对这封邮件采取行动吗？它能拿到分类好的线索，搞清楚跟进所需的所有步骤（调研、找联系人、起草邮件、记录到 CRM），识别执行这些步骤的正确工具（搜索工具、CRM 工具、邮件工具），然后自主执行那个计划吗？"**

**这个新挑战要求一个不仅能处理信息，还能推理、规划，并通过利用外部工具与数字世界交互以达成目标的 AI。团队需要的东西不仅要能思考，还要能行动。**

**AI Agent 登场。**

---

## 12.1 什么是 AI Agent

> **AI agent 是一个以 LLM 作为"大脑"、自主规划、推理并执行一系列步骤以达成特定目标的系统。**
>
> **与只是响应 prompt 的传统聊天模型不同，agent 被给予一个高层任务，然后独立地搞清楚如何完成它。**

### 对比

| | 聊天模型 | AI Agent |
| --- | --- | --- |
| **类比** | 像一位你可以提问的专家 | 像一位自主助理 |
| **示例输入** | "What are the best vegan restaurants in my area?" | "Find a highly rated vegan restaurant with a patio that is open this Saturday, and make a reservation for two." |
| **行为** | **单次、反应式的对话轮次**，给你一个列表 | **把任务拆成一系列步骤并执行** |

### Agent 的三大能力

| 能力 | 说明 |
| --- | --- |
| **Planning（规划）** | **确定达成目标所需的步骤。** 它可能决定先搜索素食餐厅，然后按评分和露台可用性筛选，最后用工具检查预订 |
| **Tool use（工具使用）** | 用**搜索引擎工具**找餐厅、用**日历工具**查日期、用**预订工具**订桌 |
| **Reasoning（推理）** | **分析每一步的结果。** 如果某家餐厅关门了，agent 会推理出它需要回头再找一家。如果成功找到并预订，它会结束任务 |

> **本质上，AI agent 通过给一个被动的 LLM 提供一套工具和有效使用这些工具的框架，把它转变成一个主动的、目标导向的问题解决者。**

## 12.2 三种工作流

**Workflow（工作流）** 是为达成特定业务成果或目标而设计的一系列相互关联的步骤或任务。**它规定了谁做什么、什么时候做、每个阶段涉及哪些信息或资源。**

工作流提供结构、一致性，常常还有自动化，帮助精简运营、提升效率、确保完成任务的方式可重复且可预测。

**根据我们赋予 AI/LLM 的自主程度，现在有三类工作流：**

| 类型 | 定义 |
| --- | --- |
| **Traditional workflows** | 无 AI |
| **AI workflows** | **AI 以预定顺序使用** |
| **Agentic workflows** | **目标导向的工作流，步骤序列具有非确定性** |

### 1. 传统工作流（Traditional Workflow）

```
User input → Step 1 → ... → Step X → Done
```

**预定义的、基于规则的自动化任务或数据转换序列**，通常用 ETL 流程、BPM 系统或集成平台（iPaaS）实现。

**特点：**

- **确定性（deterministic）**：遵循固定逻辑
- 设计用于自动化重复任务或应用间的数据移动
- **依赖显式的、预配置的规则和逻辑**，缺乏 AI 驱动工作流的适应性或决策能力
- 常由特定事件或时间表触发

> ⚠️ **传统工作流的特点是刚性的预定义步骤，常依赖擅长可预测重复任务的规则系统。但这些系统常在适应性和复杂决策上挣扎，往往需要人工介入来管理异常或应对不可预见的情况。**

**例子**：一个基于预定义标准自动排序和归档文档的简单脚本。

### 2. AI 工作流（AI Workflow）

```
User input → ... → [LLM: AI 生成响应] → ... → Done
```

**结构化的、线性的任务序列，以预定顺序应用 AI 工具**以达成特定结果。每一步都清晰定义，**一步的输出作为下一步的输入**。

**特点：**

- **强调可预测性和控制**，适合需要一致性和可靠性的流程
- **确定性**：给定相同输入，总是产生相同输出
- **通过纳入智能模型超越简单逻辑，增强复杂决策**
- 利用机器学习适应变化的条件、处理规则系统无法应对的细微任务

> ⚠️ **虽然提供了显著的效率，但它们并非完全自主，关键决策和战略指导仍依赖人工监督。**

**例子**：一个用 AI 基于情感分析路由客服工单、但仍需人工客服解决复杂问题的系统。

### 3. Agentic 工作流（Agentic Workflow）

```
                    ┌─────── AI agent ───────┐
                    │  Think  →  Plan        │
User input → ... →  │    ↑         ↓         │ → ... → Done
                    │  Reflect ← Execute     │
                    │            with tools  │
                    └────────────────────────┘
```

**纳入了能做出自主决策并采取行动以在工作流内达成目标的 AI agent。**

**特点：**

- **仍有整体结构，但 agent 在某些阶段有选择用哪些工具、如何推进的灵活性**
- **引入了一定程度的非确定性（nondeterminism）**——agent 的选择会因情境而变
- 适合需要适应性和问题解决的更复杂任务
- ⚠️ **但也要求仔细的监控和控制，确保 agent 与期望结果保持一致**

> **Agentic 工作流代表了超越简单自动化的飞跃，赋予 LLM 真正的自主性和能动性。这些系统能独立规划、执行并适应复杂任务，利用外部工具和环境反馈达成特定目标，无需持续的人工介入。**
>
> **通过与环境交互并访问实时信息，agentic 工作流甚至能随时间学习和优化其流程，在应对不可预测的挑战中变得越来越高效。**

**例子**：一个管理你旅行行程的 AI agent，根据你的偏好预订航班、酒店和活动，同时主动适应变化并提供实时更新。

## 三种工作流对比速查

| 维度 | 传统工作流 | AI 工作流 | Agentic 工作流 |
| --- | --- | --- | --- |
| **AI 参与** | 无 | 有，预定顺序 | 有，自主决定 |
| **确定性** | 确定 | 确定 | **非确定** |
| **步骤顺序** | 固定 | 固定 | **由 agent 动态决定** |
| **适应性** | 差 | 中等 | **强** |
| **人工监督** | 处理异常 | **关键决策仍需** | 需要监控对齐 |
| **适用场景** | 可预测的重复任务 | 需一致性和可靠性的流程 | **需适应性和问题解决的复杂任务** |

---

## 本章小结

> **我们把视角从反应式的 AI 交互转向了 AI agent 的主动能力。**
>
> **虽然 LLM、RAG、提示和微调在生成响应上很强大，但 AI 真正的潜力在于让模型独立行动、编排任务并与真实世界交互。这要求超越简单的聊天界面，赋予 LLM 一定程度的能动性（agency）。**

三种工作流的区别凸显了**为什么 AI agent 对于处理需要动态问题解决和工具利用的复杂多步任务至关重要**，为 AI 成为复杂数字流程中的主动参与者铺平了道路。
