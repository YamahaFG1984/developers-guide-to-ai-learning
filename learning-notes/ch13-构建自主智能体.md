你可能已经接触过 **CrewAI**（https://www.crewai.com）、**Browser Use**（https://browser-use.com）或 **Agent.ai**（https://agent.ai）这类平台。它们是探索 agent 世界的有价值途径。

> **但既然这本书叫《The Developer's Guide to AI》，我们的目标是帮你构建适合你具体需求的 AI agent。我们相信理解底层机制、具备定制 agent 的能力，对开发者至关重要。**

**可选框架：**

- **Hugging Face smolagents**（https://huggingface.co/docs/smolagents）← 本书使用
- **Google Agent Development Kit (ADK)**（https://google.github.io/adk-docs/）
- **FastMCP**（https://gofastmcp.com）

## 13.1 一个真实的多步任务

> 想象你是投资人，想知道你关心的公司 2024 Q4 赚了多少钱。听起来简单，但要找到那个数字你得：
>
> 1. 上网搜每家公司的财报
> 2. 找到 2024 Q4 报告的正确链接
> 3. 下载报告（可能是很长的文档）
> 4. 打开报告，翻找到含有你需要的营收信息的具体章节
>
> **这个多步过程对每家公司都要花时间和精力。**

> **在这类步骤并不总是相同的任务中，AI agent 真正大放异彩。**
>
> **过程不只是找到报告本身——即便是读报告、定位具体的营收数字，对每家公司也可能不同。Amazon 呈现财报的方式可能和 Apple 或 Google 不同。这使得创建一套对每家公司报告都适用的固定指令变得极具挑战性。**

## 13.2 环境搭建

> 代码在 **Python 3.13.7** 和 **Hugging Face smolagents 1.22.0** 上构建和测试。

**先建一个新的 Python 环境**（`venv` 或 Conda），帮助管理项目依赖、避免与系统上其他项目冲突。

```bash
pip install smolagents==1.22.0 "smolagents[litellm]" "smolagents[toolkit]"
```

> **smolagents 利用 LiteLLM 这类工具连接各种 LLM，包括 Google 的模型。** 因为示例用 Google Gemini Flash 模型，所以要装带 litellm 集成的 smolagents。

### 配置 API Key

从 **Google AI Studio** 或 **Google Cloud Platform** 获取 `GEMINI_API_KEY`，然后设为环境变量：

```bash
# On Linux/macOS
export GEMINI_API_KEY=your_api_key_here

# On Windows
set GEMINI_API_KEY=your_api_key_here
```

> 💡 **想在不同终端会话间永久生效**，可以把这行加到 shell 启动文件（`~/.bashrc`、`~/.zshrc`、`~/.profile`），或用 `python-dotenv` 这类库加载 `.env` 文件。

## 13.3 第一个 Agent

**书中的最小版本：**

```python
from smolagents import CodeAgent, LiteLLMModel

model_id = "gemini/gemini-2.0-flash"

model = LiteLLMModel(
    model_id=model_id,
    provider="google",
)

tools = []

agent = CodeAgent(
    tools=tools,
    model=model,
    add_base_tools=True,
    verbosity_level=1,
    max_steps=5
)

message = "Based on Amazon's Q4 2024 earnings report, what is the revenue for the quarter?"
agent.run(message)
```

**仓库中的实际版本（`part5/building-your-first-agent/01-helloAgents.py`）显式加入了两个工具：**

```python
from smolagents import CodeAgent, LiteLLMModel
from smolagents import DuckDuckGoSearchTool, VisitWebpageTool

model_id = "gemini/gemini-2.0-flash"

model = LiteLLMModel(
    model_id=model_id,
    provider="google",
)

tools = [
    DuckDuckGoSearchTool(),      # 网页搜索
    VisitWebpageTool()           # 访问网页读取内容
]

agent = CodeAgent(
    tools=tools,
    model=model,
    add_base_tools=True,
    verbosity_level=2,
    max_steps=5
)

message = "Based on Amazon's Q4 2024 earnings report, what is the revenue for the quarter?"
agent.run(message)
```

### CodeAgent 参数详解

| 参数 | 说明 |
| --- | --- |
| `tools=tools` | **给 agent 分配一组工具。这些工具是 agent 能用来完成任务的具体函数或能力** |
| `model=model` | agent 用于**推理和代码生成**的底层 LLM |
| `add_base_tools=True` | **自动包含一套标准的基本工具。** smolagents 的默认工具集包括 **DuckDuckGo 网页搜索能力**和 **Python 代码解释器** |
| `verbosity_level=1` | 控制 agent 工作时打印的信息量 |
| `max_steps=5` | **限制 agent 完成任务可采取的步骤数。** 无论是否完成任务，5 步后就停止。**这是防止 agent 无限运行的安全措施** |

### 运行结果

答案应该是 **$187.8 billion** 或包含该结果的回答。

### 底层发生了什么

> **我们指示 AI agent 去找 Amazon 2024 Q4 的营收。重要的是要认识到：LLM 在其基础状态下不具备这类具体外部数据的实时知识。要找到答案，agent 需要去查找，就像我们会做的那样！**
>
> **agent 需要从互联网搜索和检索数据的能力。** 我们在初始设置中通过 `add_base_tools=True` 赋予了它这项功能，启用了一套默认工具，其中之一就是由 **DuckDuckGo 搜索引擎驱动的网页搜索工具**。

### 🧪 动手实验

> **把 `add_base_tools=True` 参数从代码中移除再运行一遍。观察 agent 在没有显式提供网页搜索能力时，被要求找 Amazon 2024 Q4 营收的行为。**
>
> **这将说明 agent 对外部工具的依赖——用于访问超出其固有知识库的信息。**

## 13.4 Agent 与提示工程

> **构建一个能有效执行期望操作的 agent，不仅仅是选一个有能力的推理模型。提示工程的艺术与科学不能被忽视。**
>
> **我们如何通过精心设计的 prompt 指示和引导 agent（即设定上下文），在达成期望结果上扮演同等关键的角色。**

### 版本 1：普通询问

**Prompt:**
```
Show me the Q4 2024 revenue for Amazon, Google, and Apple
```

**响应：**
```
Amazon Q4 2024 Revenue: $187.8 billion,
Google Q4 2024 Revenue: $96.5 billion,
Apple Q4 2024 Revenue: $94.9 billion
```

### 版本 2：要求结构化输出

**`part5/building-your-first-agent/02.findingEarningsReport.py`**

```python
from smolagents import CodeAgent, LiteLLMModel

model_id = "gemini/gemini-2.0-flash"

model = LiteLLMModel(
    model_id=model_id,
    provider="google",
)

tools = []

agent = CodeAgent(
    tools=tools,
    model=model,
    add_base_tools=True
)

message = "Show me the Q4 2024 revenue for Amazon, Google and Apple and compare them in a table."
agent.run(message)
```

**响应：**

| Company | Q4 2024 Revenue (USD) |
| --- | --- |
| Amazon | $187.8 billion |
| Google (Alphabet) | $96.5 billion |
| Apple | $94.9 billion |

> **这个修订后的指令显式请求了结构化输出，让财务结果的分析和比较方便得多。**

## 本章小结

- 用 **smolagents** 构建了第一个 agent，采用**可定制的、基于代码的方式**
- **`add_base_tools=True`** 让 agent 获得网页搜索和 Python 解释器能力
- **`max_steps`** 是防止无限运行的安全措施
- **提示工程对 agent 依然关键**：精心设计的指令能引导 agent 不仅找到信息，还能以你想要的结构化格式呈现（比如对比表格）

---

## 练习

1. **调整 `max_steps` 参数**。观察增大或减小这个值如何影响 agent 完成更复杂任务的能力，或它是否会过早停止。
2. **用更复杂的输出格式请求挑战 agent**。比如让它总结一个主题，然后用要点列出三条关键收获，接着用一小段解释每一条。
