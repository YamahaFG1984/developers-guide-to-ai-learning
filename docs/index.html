核心比喻：做 AI 厨师，而不是 AI 建筑师

训练一个大模型要花几十万到几百万美元，那是“AI 建筑师”的工作。我们是AI 厨师： 挑选合适的原料（预训练模型、RAG、微调），用恰当的技法（提示工程、工具调用）把它们组合起来，做出解决真实问题的菜。

环境准备（一次性）

🦙

Ollama

第一到三部分用它在本地跑 Llama 3.2 和 embedding 模型，免费。

🐍

Python 3.13

第 3 章起的主要语言。每个 Part 建议一个独立的虚拟环境。

🟢

Node.js

第 2 章的服务和各部分的 React 前端。

🔑

API key

第五部分需要 Gemini API key；费用管理器示例需要 MongoDB（可选）。

# Ollama：https://ollama.com
ollama serve                        # 终端 1：启动服务
ollama run llama3.2                 # 终端 2：3B 模型，约需 6GB 内存
ollama run llama3.2:1b              # 低配替代：1B 模型，约需 2GB 内存
ollama pull mxbai-embed-large       # 第三部分 RAG 需要的 embedding 模型

# Python 虚拟环境（每个 Part 一个）
pyenv install 3.13.7
pyenv virtualenv 3.13.7 developers-guide-to-ai-part1
pyenv activate developers-guide-to-ai-part1
python -m pip install -r requirements.txt

怎么用这套教程

  • 每章配合代码跑一遍。看懂概念不等于会用，尤其是 prompt —— 同一个 prompt 在不同模型上的表现差异，只有亲手试才有感觉。
  • 把每章末尾的练习当必做题。它们往往指向书里没展开但很关键的细节。
  • 第四部分需要耐心。微调在 CPU 上可能跑好几个小时，可以先读懂 notebook，再决定是否完整跑一遍。
  • 右下角的按钮可以切换深浅色。小屏幕上点左上角的菜单按钮打开目录。
