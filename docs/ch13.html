构建自主智能体

环境搭建

建议先建一个新的虚拟环境（venv 或 Conda）。书中基于 Python 3.13.7 和 smolagents 1.22.0：

pip install smolagents==1.22.0 "smolagents[litellm]" "smolagents[toolkit]"

smolagents 通过 LiteLLM 连接各家模型（包括 Google Gemini）。从 Google AI Studio 或 Google Cloud 获取 API key，设为环境变量：

export GEMINI_API_KEY=your_api_key_here     # Linux / macOS
set GEMINI_API_KEY=your_api_key_here        # Windows
# 想永久生效：写进 ~/.zshrc / ~/.bashrc，或用 python-dotenv 读 .env 文件

第一个 Agent

from smolagents import CodeAgent, LiteLLMModel
from smolagents import DuckDuckGoSearchTool, VisitWebpageTool

model_id = "gemini/gemini-2.0-flash"

model = LiteLLMModel(                 # 用 LiteLLM 连接 Gemini（读取 GEMINI_API_KEY）
    model_id=model_id,
    provider="google",
)

tools = [
    DuckDuckGoSearchTool(),           # 网页搜索
    VisitWebpageTool()                # 访问网页、读取内容
]

agent = CodeAgent(
    tools=tools,
    model=model,
    add_base_tools=True,              # 再加上默认工具集（搜索 + Python 解释器）
    verbosity_level=2,                # 打印多少过程信息
    max_steps=5                       # 最多走 5 步，防止无限运行
)

message = "Based on Amazon's Q4 2024 earnings report, what is the revenue for the quarter?"
agent.run(message)
参数作用
tools分配给 Agent 的工具列表 —— 它能用来完成任务的具体函数或能力
model负责推理和写代码的 LLM
add_base_tools=True自动加入默认工具：DuckDuckGo 网页搜索和 Python 代码解释器
verbosity_level控制运行时打印的信息量，调高能看到每一步的思考和代码
max_steps=5最多走 5 步，不管完成没有都停下。这是防止 Agent 无限循环、无限烧钱的安全阀

运行后，答案应该是 $187.8 billion（或包含这个数字的回答）。

它是怎么做到的？

LLM 本身不知道 Amazon 2024 Q4 的营收（训练截止之后，第 1 章的“知识截止”）。所以 Agent 必须像我们一样去查。 CodeAgent 的特点是：它让 LLM 写一段 Python 代码来调用工具，执行代码后把结果（观察）喂回给 LLM，再决定下一步：

ⓘ 书中的最小版本

书中一开始给的是 tools = [] 加 add_base_tools=True 的版本 —— 只靠默认工具（DuckDuckGo 搜索 + Python 解释器）也能完成任务。仓库里的版本额外显式加入了 VisitWebpageTool，让 Agent 能直接读网页正文。

🧪 动手实验：拿走工具会怎样？

把 add_base_tools=True 去掉，并把 tools 设为空列表，再运行一次。观察 Agent 没有搜索能力时的表现 —— 它要么承认不知道，要么凭训练数据“猜”。这直观地说明了：Agent 获取外部信息的能力，完全来自你给它的工具。

Agent 也需要好的提示

光有强大的模型还不够。你怎么描述任务（也就是给 Agent 设定上下文），对结果同样关键。比较两个版本：

版本 1：普通提问
Show me the Q4 2024 revenue for Amazon, Google, and Apple
Amazon Q4 2024 Revenue: $187.8 billion, Google Q4 2024 Revenue: $96.5 billion, Apple Q4 2024 Revenue: $94.9 billion
版本 2：要求表格对比
Show me the Q4 2024 revenue for Amazon, Google and Apple and compare them in a table.
| Company | Q4 2024 Revenue | | Amazon | $187.8 billion | | Google (Alphabet) | $96.5 billion | | Apple | $94.9 billion |
from smolagents import CodeAgent, LiteLLMModel

model = LiteLLMModel(model_id="gemini/gemini-2.0-flash", provider="google")

agent = CodeAgent(
    tools=[],
    model=model,
    add_base_tools=True
)

message = "Show me the Q4 2024 revenue for Amazon, Google and Apple and compare them in a table."
agent.run(message)

多公司查询时，Agent 会对每家公司重复“搜索 → 读取”的循环，最后汇总。这正是第 12 章说的非确定性：步骤数量和顺序由 Agent 根据情况决定，而不是你事先写死。

小结

  • 用 smolagents 的 CodeAgent 搭起了第一个 Agent：LLM 写 Python 代码调用工具。
  • add_base_tools=True 给了 Agent 网页搜索和 Python 解释器；没有工具，它就查不到训练数据以外的信息。
  • max_steps 是防止无限运行的安全阀。
  • 提示工程对 Agent 同样关键：清楚说明想要的输出形式（比如对比表格），结果会好用得多。

动手练习

  1. 调整 max_steps：调小时 Agent 会不会还没找完就被迫停下？调大时对复杂任务有什么帮助？
  2. 给 Agent 更复杂的输出要求：比如让它总结一个主题，列出三条要点，再用一小段话解释每一条。
  3. 把 verbosity_level 调到 2，仔细看 Agent 每一步生成的代码和观察结果，画出它实际走过的步骤。
