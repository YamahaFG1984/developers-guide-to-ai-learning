完整的 FastAPI 服务

先看全貌，一共不到 40 行。接下来我们一段段拆开：

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from fastapi.middleware.cors import CORSMiddleware
from ollama import Client

from pydantic import BaseModel

app = FastAPI()

app.add_middleware(
  CORSMiddleware,
  allow_origins=["*"],
  allow_credentials=True,
  allow_methods=["*"],
  allow_headers=["*"],
)

client = Client()


class ChatRequest(BaseModel):
  question: str


def generate_stream(question: str):
  result = client.generate(stream=True, model="llama3.2", prompt=question)

  for chunk in result:
    if chunk.response:
      print('\nReturned GenerateResponse object for chunk:\n')
      print(chunk.model_dump_json(indent=2))

      yield chunk.response


@app.post("/")
def chat(chatRequest: ChatRequest):
  return StreamingResponse(
    generate_stream(chatRequest.question), media_type="text/plain")

第一段：创建应用和客户端

from fastapi import FastAPI                              # ❶ 导入四个类
from fastapi.responses import StreamingResponse
from fastapi.middleware.cors import CORSMiddleware
from ollama import Client

app = FastAPI()                                          # ❷ 创建应用

app.add_middleware(                                      # ❸ 加 CORS 中间件
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

client = Client()                                        # ❹ Ollama 客户端，默认配置
类作用
FastAPI应用主类，定义接口、处理请求、配置行为的中心
StreamingResponse分块（而非一次性）把数据发给客户端 —— 正好用来流式返回 LLM 回答
CORSMiddleware和 Node 版一样，自动处理跨域
Client和本地 Ollama 通信的客户端
👉 Python 语法点：命名参数

allow_origins=["*"] 这种 名字=值 的写法叫关键字参数。 它不依赖参数顺序，一眼能看出每个值是干什么的，Python 里特别常见，尤其是可选参数。 JS 里类似的效果要靠传一个对象 { allowOrigins: ['*'] }。

第二段：Pydantic 模型与装饰器

from pydantic import BaseModel          # ❶ 随 FastAPI 一起安装，不用单独装

class ChatRequest(BaseModel):           # ❷ 括号里是父类：继承 BaseModel
    question: str                       #    一个字符串类型的字段

@app.post("/")                          # ❸ 装饰器：把下面的函数注册为 POST / 的处理函数
def chat(chatRequest: ChatRequest):     # ❹ 参数类型告诉 FastAPI 请求体应长什么样
    ...

Pydantic 让你用一个普通的类描述 JSON 的结构。 ChatRequest 说的是：“请求体必须是一个对象，里面有个字符串 question”。 FastAPI 看到 chat 的参数类型是 ChatRequest，就会自动完成三件事：

那个 @app.post("/") 叫装饰器（decorator）。第一次看有点像魔法， 但它的意思很简单：“把下面这个函数挂到 POST / 这个地址上”。 全书会大量用到装饰器 —— 它是 Python 里把你的代码“接入”某个框架的最常见方式。 到第 14 章，你会看到用 @tool 装饰器把一个函数变成 AI 可调用的工具。

第三段：yield 与生成器

def generate_stream(question: str):
    result = client.generate(model="llama3.2", stream=True, prompt=question)  # ❶ 开启流式

    for chunk in result:                # ❷ 遍历模型吐出的每一块
        if chunk.response:              # ❸ 有内容才处理
            yield chunk.response        # ❹ 交出这一块，然后暂停在这里

这段代码的灵魂是 yield。函数体里只要出现 yield，它就变成了生成器函数。 调用它时不会立刻执行，而是返回一个“生成器对象”。每当有人向它要下一个值，它才往下跑， 跑到 yield 就把值交出去，然后原地暂停，等下一次被叫醒。

🍣 打个比方：回转寿司

普通函数像外卖：全部做好装盒，一次性送到（return 一个完整列表）。 生成器像回转寿司：厨师做好一盘就放上传送带（yield），你吃完一盘再来下一盘， 不用等所有菜都做完才开吃。

最后，路由函数只需要把生成器交给 StreamingResponse，剩下的它全包了：

@app.post("/")
def chat(chatRequest: ChatRequest):
    return StreamingResponse(
        generate_stream(chatRequest.question),   # 生成器对象（此时还没开始执行）
        media_type="text/plain")                 # 告诉客户端：纯文本

最容易踩的坑：缩进就是语法

从 JavaScript、Java、C# 过来的同学注意：那些语言用花括号 {} 划分代码块，缩进只是为了好看。 Python 没有花括号，行首有几个空格决定了这一行属于哪个 if、for 或 def。

⚠ 统一用空格，别混用 Tab

保持一致的缩进（通常 2 或 4 个空格），并让编辑器自动处理。Tab 和空格混用是新手最常见的神秘报错来源。

小结

  • Python 是 AI 开发的首选语言，从这里开始全书示例都用 Python。
  • 用虚拟环境隔离每个 Part 的依赖；安装库用 python -m pip。
  • Pydantic 用类描述 JSON 结构，自动解析和校验（第 6 章还会用它约束 LLM 的输出）。
  • 装饰器把函数接入框架；生成器（yield）“要一个给一个”，天生适合流式。
  • Python 的缩进就是语法，务必保持一致。
