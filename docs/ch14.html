第 14 章 · 工具与 MCP

用工具扩展智能体

上一章的 Agent 能搜索互联网，但它仍然只能接触公开信息。真正的能动性，意味着能读写你的私有数据库、保存文件、调用内部系统。 这一章我们先用 @tool 给 Agent 写自定义工具，再用 MCP（Model Context Protocol） 把工具做成任何 AI 都能接入的标准服务。

本章目标

  • 用 smolagents 的 @tool 装饰器写自定义工具，掌握写好工具的四条原则
  • 理解 MCP 要解决的问题，以及 hosts / clients / servers 架构
  • 认识 MCP server 的三类能力：Tools、Resources、Prompts
  • 用 FastMCP 写一个 MCP server，用 Postman 测试，接入 Claude Desktop
  • 区分 stdio 和 HTTP 两种传输方式，用 Pydantic 定义复杂的工具输入输出

写一个自定义工具

给 Agent 一个新任务：

任务
Find the latest stock price for Apple, Google and Amazon. Convert that into a table and save it to a file.

查股价可以靠搜索，但“保存到文件”这种动作，Agent 和 LLM 天生都不会。我们得给它一个工具 —— 其实就是一个普通的 Python 函数：

from smolagents import CodeAgent, tool

@tool                                     # ❶ 装饰器：把函数注册成 Agent 能用的工具
def save_file(data: str) -> None:         # ❷ 描述性的名字 + 精确的类型提示
    """                                   # ❸ docstring：给 LLM 看的说明书
    Save the data to a file

    Args:
        data: The data to save to the file

    """
    with open("investments.txt", "w") as f:    # ❹ 真正干活的逻辑
        f.write(data)

agent = CodeAgent(
    tools=[save_file],                    # ❺ 把工具交给 Agent
    model=model,
    add_base_tools=True
)

Agent 并不读你的函数实现，它是通过函数名、类型提示和 docstring 来理解这个工具能干什么、需要什么参数：

写好工具的四条原则

🏷

描述性的函数名

save_file 一看就懂，f1 让 LLM 去猜。

🔠

精确的类型提示

所有参数和返回值都加类型，框架靠它们理解输入输出。

📖

完整的 docstring

这是 LLM 主要的说明书：工具干什么、什么时候用。

✏

逐个说明参数

用平实的语言说明每个参数要传什么。

工具多了之后：复用的难题

Agent 越来越多，工具也越来越多。每做一个新 Agent 就把数据库查询、网页抓取工具复制一遍？既浪费时间，也难以维护。 打包成库可以缓解，但每个框架的工具接口都不一样。更根本的办法是一个标准协议：

MCP 是什么

Model Context Protocol 定义了一套标准规则和一门“通用语言”： 任何 Agent 都能用它发现、理解、调用任何遵守标准的工具和数据源；同时它也规定了工具和数据源该如何描述自己。 它采用熟悉的客户端-服务器模型：

角色是什么
Host（宿主）主 AI 应用，比如 LLM 桌面应用或 IDE，负责发起和管理连接
Client（客户端）嵌在 Host 里，与一个 Server 保持一对一连接，在 Host/LLM 和 Server 之间传话
Server（服务器）外部程序或服务，向客户端提供特定的能力和上下文

MCP Server 能提供的三类东西

🔧

Tools 工具

可执行的函数。LLM 可以调用它们来执行动作、访问外部系统 —— 给 AI 用的“函数”。

📄

Resources 资源

可读取的数据或动态内容，提供给 LLM 作为参考，不一定执行动作。

📝

Prompts 提示

可复用的 prompt 模板和结构化工作流，把常见交互标准化。

两种传输方式

🔑 为什么 MCP 很重要

MCP server 已经覆盖了数据库、支付、搜索、可观测性等几乎所有技术领域。它让不懂技术的人也能和复杂系统“对话”。 一位经理可以直接问：“过去三个季度的 AWS 花费是多少？和运行中的服务器数量画在一张图上。” AI 通过 AWS 的 MCP server 拿到账单和服务器历史，拼成结果。以前要花几小时登录控制台、到处翻找的事，几分钟就完成了。

动手：第一个 MCP Server

我们用 FastMCP（书中基于 2.12.4）写一个“特殊计算器”，它的四则运算都带一点小把戏：

工具实际计算例：10 和 10
add(num1, num2)num1 + num2 + num230
subtract(num1, num2)num1 - num2 - num2-10
multiply(num1, num2)num1 × num2 × num21000
divide(num1, num2)num1 / num2 / num20.1
🤡 为什么故意做个“傻”计算器？

学新东西的好办法就是做点简单甚至傻乎乎的东西。结果“不正常”，你就能立刻确认：是 AI 真的调用了你的工具，而不是它自己心算的。

from fastmcp import FastMCP

mcp = FastMCP(
    name="My Special Calculator",              # ❶ 名字：AI 理解这个 server 用途的第一线索
    instructions="""                           # ❷ 说明：相当于 server 的 README
    This is a special calculator that does some special things.
    It can add, subtract, multiply, and divide in some special ways.
    """,
)


@mcp.tool                                      # ❸ 注册为 MCP 工具
def add(num1: int, num2: int) -> int:          #    类型提示 → 自动生成 JSON schema
    return num1 + num2 + num2


@mcp.tool
def subtract(num1: int, num2: int) -> int:
    return num1 - num2 - num2


@mcp.tool
def multiply(num1: int, num2: int) -> int:
    return num1 * num2 * num2


@mcp.tool
def divide(num1: int, num2: int) -> int:
    return num1 / num2 / num2


if __name__ == "__main__":
    mcp.run()                                  # 默认使用 stdio 传输
  • name：像对待变量名一样认真。mcp_server 逼 AI 去猜，PayrollReportGenerator 一眼就懂。
  • instructions：server 的公开文档，第一次发现它的用户（和 AI）会先看到这段话。
  • 类型提示：FastMCP 用它们生成工具输入输出的 JSON schema，LLM 靠 schema 正确组织参数。
python mySpecialCalculator-mcp-server.py
# Starting MCP server 'My Special Calculator' with transport 'stdio'

用 Postman 测试

  1. 新建请求，类型选 MCP不是普通的 HTTP 请求。
  2. 选择 stdio，填写启动命令用虚拟环境里的 Python运行脚本，例如 path/.venv/bin/python path/mySpecialCalculator-mcp-server.py，避免和系统 Python 的包冲突。
  3. 点 Connect连接成功后，立刻能看到 server 暴露的四个工具。
  4. 点击工具，填参数，RunPostman 会根据工具的 schema 自动生成表单，运行后显示返回结果。

换成 HTTP：让别人也能用

stdio 把 server 限制在本机、只能自己用。想让多个客户端通过网络连接，换成 HTTP 传输，server 就变成了一个可以部署在任何地方的 Web 服务：

mcp.run(transport="http", host="0.0.0.0", port=8000)
ⓘ 注意

截至书中撰写时，Claude Desktop 还不支持 HTTP 传输的 MCP server。

进阶：复杂的输入输出

真实世界的工具很少只收两个整数。我们经常要处理结构化的消息，需要校验 AI 传来的数据，也要保证返回值符合可预测的格式。 答案又是 Pydantic。下面是一个连接 MongoDB 的费用管理器： 

from pymongo import AsyncMongoClient
from pydantic import BaseModel, Field
from datetime import datetime
from typing import List, Optional
from bson import ObjectId
from fastmcp import FastMCP

mcp = FastMCP(
    name="My Expense Manager",
    instructions="This is a simple expense manager that allows you to add, find, get and count expenses",
)

client = AsyncMongoClient("mongodb://localhost:27017?directConnection=true")
expenses = client.get_database("test").get_collection("expenses")


class Expense(BaseModel):                                     # ❶ 用 Pydantic 描述结构
    _id: Optional[ObjectId] = None
    description: str = Field(description="The description of the expense")
    amount: float = Field(description="The amount of the expense")
    date: Optional[datetime | str] = Field(
        description="The date of the expense", default=None)


@mcp.tool(name="add_expense", description="Add a new expense")
async def add_expense(data: Expense) -> ObjectId:             # ❷ 作为工具的输入类型
    try:
        result = await expenses.insert_one(data.model_dump(mode="json"))
        return result.inserted_id
    except Exception as e:
        raise Exception("Unable to add the expense due to the following error: ", e)


@mcp.tool()
async def find_expenses() -> List[Expense]:                   # ❸ 用 docstring 描述用途
    """
    Find all expenses
    Args:
        None
    Returns:
        List[Expense]: A list of expenses
    """
    list_of_expenses = await expenses.find().to_list(length=100)
    for expense in list_of_expenses:
        expense["_id"] = str(expense["_id"])
    return list_of_expenses

小结

主题要点
自定义工具@tool + 描述性函数名 + 精确类型提示 + 完整 docstring，它们是 LLM 的“说明书”
复用问题每个 Agent 重写工具很低效；打包成库可以；MCP 更优雅
MCP通用标准，让任何 Agent 连接任何工具和数据源
架构Host / Client / Server；Server 提供 Tools / Resources / Prompts
传输stdio（本地、单用户）vs HTTP（联网、多客户端）
FastMCPFastMCP(name, instructions) + @mcp.tool + mcp.run()
测试与集成Postman 验证工具；fastmcp install claude-desktop 一键接入
